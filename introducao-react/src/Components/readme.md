## 🎯 Objetivo

Criar um componente em React que utilize um objeto para armazenar informações de um tema escolhido pelo aluno e apresentar essas informações visualmente na página.

## 📌 O que fazer

Escolha um tema de sua preferência.

### Exemplos:

Filmes
Séries
Jogos
Carros
Animais
Esportes
Países
Comidas
Celulares
Personagens

## Etapas:

1. Crie um componente React relacionado ao tema escolhido.
2. Crie um objeto contendo informações sobre o tema.
3. O objeto deverá possuir no mínimo 3 propriedades.
4. Utilize o objeto dentro do componente para apresentar as informações na tela.
5. Crie uma apresentação visual utilizando HTML/JSX e CSS.
6. O resultado deverá ser organizado e fácil de visualizar.

### 💡 Exemplo de ideia

  Criando um Componente com Objeto  

Nome do filme
Ano
Gênero
Diretor
Nota

O aluno deverá escolher quais propriedades utilizar, respeitando o mínimo de 3 propriedades.

### 📸 Entrega

A entrega deverá conter 2 prints:

Print 1: parte visual do projeto funcionando no navegador.
Print 2: código do componente criado.

Os dois prints deverão ser anexados na tarefa.

### ⚠️ Observações
O tema é livre.
O componente deve ser criado pelo aluno.
O objeto deve possuir no mínimo 3 propriedades.
A apresentação visual deve utilizar CSS.
Não é necessário copiar o exemplo utilizado em sala; cada aluno deve escolher seu próprio tema.
